
# Live Demonstration Plan

## 1. Application Launch
Open the application and show the home page.

## 2. User Request
Enter a natural-language ticket booking request.

## 3. Ticket Discovery
Show the available tickets.

## 4. Seat Selection
Select seats and explain availability.

## 5. Pricing
Show ticket price, discounts, taxes and total amount.

## 6. Payment
Demonstrate the payment sandbox.

## 7. Confirmation
Display booking ID and QR ticket.

## 8. Final Verification
Show the booking status.

## Backup Plan

- Keep screenshots of successful operations.
- Prepare sample booking data.
- Ensure the application starts before the presentation.
- Have a recorded demo available if the live demo fails.

## Expected Outcome

The audience should understand the complete ticket booking process.
